How routing works

  • Each incoming mail is matched against the inboxes in priority order (lowest first); the first whose domain and format match gets it, and the real address (e.g. any@example.com) is shown next to the catch-all address.
  • Inboxes with an address list are checked first and receive exactly those addresses (e.g. any.example@{{$d.Domain}} → Inbox A, any-*@{{$d.Domain}} → Inbox C).
  • Mail that matches no inbox goes to the default inbox.
  • Several inboxes on one domain: give each an {inbox} marker, e.g. {inbox}-{local}={domain} → team1-any=example.com@{{$d.Domain}}. Or give an inbox its own domain (needs its own Email Routing catch-all).
