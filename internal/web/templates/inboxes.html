How routing works

  • Each incoming mail is matched against the inboxes in priority order (lowest first); the first whose domain and format match gets it, and the real address (e.g. b@gmail.com) is shown next to the catch-all address.
  • Mail that matches no inbox goes to the default inbox.
  • Several inboxes on one domain: give each an {inbox} marker, e.g. {inbox}-{local}={domain} → team1-b=gmail.com@{{$d.Domain}}. Or give an inbox its own domain (needs its own Email Routing catch-all).
